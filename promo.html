一个 HTML，打开即用的影视中心

纯前端 · 单文件 · 零构建的影视聚合播放器。多源并行搜索，播放干净利落，支持投屏、选集、倍速与键盘快捷键。同时提供公开 CDN，可一行代码嵌入你自己的页面。

重点功能

该有的都有，不该有的一个都没有

单文件，零构建

整个应用就是一个 index.html。双击打开即用，无需安装、无需打包、无任何构建工具。

完全开源

以 AGPL-3.0-or-later 许可发布，源码公开可审计。任何人可自由使用、修改与再分发。

公开 CDN

组件库与接口 SDK 经 jsDelivr 提供，一行 <script> 即可嵌入你自己的网页。

影视资源多

支持多个公开采集接口并行搜索，一次关键词聚合多源结果，命中率更高、可切换线路。

播放简洁

干净播放器：画质 / 画幅 / 倍速、选集与线路、全屏与小窗、手势控制、键盘快捷键，还支持投屏。

项目自身无广告

不接入任何广告、统计或追踪。数据全部存在你的浏览器本地，绝不上传。

完整说明

三种用法，按需选择

1

在线体验（最快）

点击上方「立即体验」即可直接使用，无需下载。页面部署于 GitHub Pages。

https://silverbullet-liang.github.io/tvbox-center/

2

本地运行

下载 index.html，双击用浏览器打开；部分接口有跨域限制时，用本地服务器：

# 在文件所在目录执行
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000/index.html
3

嵌入你自己的页面（CDN）

引入组件库并挂载，即得一整套影视中心（含 Pro 全部功能）：

<div id="tvbox-app" style="height:100vh"></div>
<script src="https://cdn.jsdelivr.net/gh/silverbullet-liang/tvbox-center@v1.2.1/dist/tvbox-center.min.js"></script>
<script>
  TVBox.mount('#tvbox-app', {
    sources: [{ key:'lzi', name:'量子资源', api:'https://example.com/api.php/provide/vod/' }]
  });
</script>
